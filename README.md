# BaseBuddy

**BaseBuddy** is a command-line tool written in C that converts numbers between various numeral systems, such as decimal, binary, octal, and hexadecimal — and even supports any base from 2 to 36.

## 🔧 Features

- Convert numbers between bases (2 to 36)
- Command-line interface
- Lightweight and easy to use

## 🧱 Build

```bash
gcc basebuddy.c -o basebuddy
